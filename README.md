# midi 信号の仕様

範囲はC2 - C5でオクターブごとにセマンティックにマッピングされている。\
全てのmidi channelに同じ信号がマッピングされている。\
ノートのデュレーションは全て10ms。
# midi マッピング
マッピングのセマンティクス

## C2- リズム隊
- C2: drums, bd, kick
- D2: hihats
- E2: snare, clap
- F2: toms, その他パーカッション
- G2: ブレイクビーツ
- A2: ノイズ

## C3- ベース
- C3: ベース

## C4- 和音・メロディー
- C4: 和音、パッド
- D4: プラック
- E4: メロディー
