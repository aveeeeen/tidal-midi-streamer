# midi 信号の仕様

範囲はC2 - C5でオクターブごとにセマンティックにマッピングされている。\
全てのmidi channelに同じ信号がマッピングされている。\
ノートのデュレーションは全て10ms。
# midi マッピング
マッピングのセマンティクス

## C2- リズム隊
- C2-36: drums, bd, kick
- D2-38: hihats
- E2-40: snare, clap
- F2-41: toms, その他パーカッション
- G2-43: ブレイクビーツ
- A2-45: ノイズ

## C3- ベース
- C3-48: ベース

## C4- 和音・メロディー
- C4-60: 和音、パッド
- D4-62: プラック
- E4-64: メロディー
